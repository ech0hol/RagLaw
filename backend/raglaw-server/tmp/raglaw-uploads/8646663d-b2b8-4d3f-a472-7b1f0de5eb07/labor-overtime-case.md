# 劳动争议典型案例：加班费争议

## 基本案情

张某于2022年3月入职某科技公司，担任软件开发工程师，双方签订三年期劳动合同，约定月工资15000元。2023年6月，张某因公司长期安排周末加班但未支付加班费，向劳动仲裁委员会申请仲裁。

## 争议焦点

1. 张某周末加班是否属于用人单位安排；
2. 加班费计算基数应如何确定；
3. 用人单位是否应支付经济补偿。

## 裁判要旨

仲裁委员会认为，用人单位提供的考勤记录与张某提交的微信工作记录相互印证，能够证明张某在多个周末存在用人单位安排的加班事实。用人单位未支付加班费的行为违反了《中华人民共和国劳动法》第四十四条之规定。

依据《劳动合同法》第三十八条、第四十六条，用人单位未及时足额支付劳动报酬，劳动者解除劳动合同的，用人单位应当支付经济补偿。

## 处理结果

裁决用人单位支付张某加班费12800元及解除劳动合同经济补偿15000元。
