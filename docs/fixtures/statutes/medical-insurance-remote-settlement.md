# 基本医疗保险异地就医直接结算政策摘要

## 备案要求

参保人员跨省异地就医前，应通过国家医保服务平台 APP、地方医保小程序或参保地经办机构办理异地就医备案。未按规定备案的，原则上不能直接结算，需回参保地手工报销。

## 直接结算范围

参保人员备案后，在已开通异地就医直接结算的定点医疗机构就医，符合规定的住院、门诊费用可按参保地政策直接结算。

## 急诊抢救

因急诊抢救未能事先备案的，可按规定视同已备案，享受异地就医直接结算服务。

## 报销政策执行

异地就医医疗费用结算执行参保地规定的支付范围、起付标准、最高支付限额和报销比例。

## 门诊慢特病

高血压、糖尿病、恶性肿瘤门诊放化疗、尿毒症透析、器官移植术后抗排异治疗等门诊慢特病相关费用，可按规定跨省直接结算。
